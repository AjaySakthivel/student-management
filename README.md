\# Student Management System



A backend application built using Java, Spring Boot, MySQL, and REST APIs for managing student information, marks, and attendance.



\## Technologies Used



\- Java 21

\- Spring Boot

\- Spring Data JPA

\- MySQL

\- REST API

\- Postman

\- Maven

\- Git \& GitHub



\## Features



\- Student CRUD operations

\- Search students by name

\- Add, update, view and delete marks

\- Calculate average marks

\- Record and view attendance

\- Calculate attendance percentage

\- Student academic summary

\- Input validation
